# 微信小游戏精选合集 (WeChat Mini-Games Collection)

🎮 沉浸式还原微信小游戏经典体验，内置三大爆款现象级小游戏：**《经典跳一跳》**、**《羊了个羊》**与**《合成大西瓜》**。

支持逼真的**微信真机外壳/全屏视窗切换**、**原生微信右上角胶囊菜单 (`··· | ⭕`)**、**微信好友排行榜**、**朋友圈战绩炫耀海报**、**每日7天签到与幸运大转盘**以及**全场景玩法指南**。

---

## ✨ 核心特色

### 1. 经典《跳一跳》(Jump & Jump)
- **2.5D 等距视角物理引擎**：支持触屏/鼠标长按蓄力，或**键盘空格键 (Space)** 长按蓄力，松开按抛物线起跳翻滚。
- **靶心连击倍增**：连续命中方块正中心靶心获得 `+2, +4, +6, +8...` 梯级高分音效与粒子光环。
- **隐藏彩蛋彩票**：在黑胶唱片机、7-Eleven便利店、顺丰快递盒、魔方上方静止停留 2 秒，自动触发专属声效与 `+10 ~ +15` 隐藏加分！
- **免死复活机制**：跌落后支持复活一次，打破历史记录触发全屏撒花。

### 2. 热血三消《羊了个羊》(Sheep a Sheep)
- **真实多层立体叠牌遮挡**：未被上层覆盖的高亮牌才可拾取，被压在下方的阴影牌动态禁用。
- **7格黄金卡槽**：凑齐 3 张相同图案即刻消除并播放欢快音效，卡槽堆满 7 张且无法消除则挑战失败。
- **三大救命法宝**：
  - 移出 3 张卡牌到暂存区
  - 撤销上一步
  - 全局打乱重新洗牌
- **全国羊群省份榜**：第 1 关热身教学，第 2 关魔鬼级千层牌山；通关为你的省份战队增添领头羊！

### 3. 解压物理《合成大西瓜》(Synthetic Big Watermelon)
- **11阶水果进化链**：葡萄 🍇 ➔ 樱桃 🍒 ➔ 橘子 🍊 ➔ 柠檬 🍋 ➔ 猕猴桃 🥝 ➔ 番茄 🍅 ➔ 桃子 🍑 ➔ 菠萝 🍍 ➔ 椰子 🥥 ➔ 半瓜 🍉 ➔ 完整大西瓜 🍉👑。
- **重力与弹性碰撞**：顶部带有虚线瞄准轨迹与「下一个水果」实时预览；双球碰撞实时融合并伴随果汁爆浆粒子与弹性动量传递。
- **警戒虚线警报**：顶部红色警戒虚线实时监控，水果堆积超过警戒线进入 3.5 秒倒计时危机。

### 4. 微信生态系统
- **微信胶囊菜单**：点击右上角 `···` 展开操作面板（转发好友、生成海报、关于、静音切换），点击 `⭕` 随时返回小游戏大厅。
- **朋友圈炫耀海报生成器**：一键生成带微信头像、分数徽章与二维码的战绩卡片，支持一键复制炫耀文案与保存。
- **好友排行榜与点赞**：跳一跳榜、羊群榜、大西瓜榜，支持给好友点赞互动，查看超越好友比例。
- **每日福利**：7天签到奖励与 100% 必中幸运大转盘。
- **纯 Web Audio 声音合成**：无需依赖外部音频网络文件，蓄力升调、蹦跳落地、羊叫咩咩与爆浆音效即点即响。

## 🚀 本地开发与运行

### 安装依赖
```bash
npm install
```

### 启动本地开发服务器
```bash
npm run dev
```
启动后在浏览器访问 `http://localhost:3000` 即可开始游玩。

### 项目构建
```bash
npm run build
```

---

## 🛠️ 技术栈

- **框架**: React 19 + TypeScript + Vite
- **样式**: Tailwind CSS
- **音频引擎**: Web Audio API (零网络依赖原生合成音效)
- **动效**: Canvas 2D / 2.5D Isometric + Canvas Confetti + Motion
- **图标**: Lucide React
