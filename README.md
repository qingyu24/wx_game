# 雾灯归途 · Mist Lantern

从原来的微信休闲小游戏合集重构的中文单机剧情 RPG。提灯人沈砚进入一座逐渐遗忘居民的山城，寻找姐姐沈栖，并决定记忆应该由谁保管。

- 八章完整主线，72 个剧情交互地点；每章都有调查、机关、抉择、可选人物支线与首领。
- 24 张可行走回廊，独立布局、迷雾视野、相邻符灯联动、铜钥、补给匣、72 段旧札与最多 48 场不会刷新的回廊遭遇。
- 八场主线遭遇、八个有不同机制的首领；公开敌方意图，短刃回灵、灯术削韧、防御、共鸣、药散、灯油与伙伴援助。
- 三类可升至五阶的装备、有限资源商店、章节回访、八份支线旧物、三种结局。
- 自动存档及上次有效备份、三个手动栏位、JSON 导入导出、战败重试。战斗结束才写入自动存档，刷新会恢复战前检查点。
- AI 生成的统一风格场景、四位人物肖像、八种敌人和透明角色素材；没有运行时 AI 请求、密钥、签到、排行榜或抽奖。
- 桌面与手机适配，可减弱动态效果、增大正文、开启本地合成的氛围音乐。

**时长说明：**剧情设计以约 10 小时为目标。当前版本已经完成八章到三种结局的可玩闭环与自动通关验证，但没有经过真人计时试玩，不能把章节数量当成已验证的十小时内容量。真实时长必须在阅读、解谜和完整探索试玩后校准；不通过强制等待、体力或重复刷怪补足。

## 开始游戏

需要 Node.js 20.19+（推荐 22）。

```sh
npm ci
npm run dev
```

浏览器访问终端显示的地址，默认 `http://localhost:3000`。

```sh
npm test                 # 剧情、地图可解性、战斗与存档逻辑
npm run build            # 检查入口并构建 dist/
npm run test:browser      # 本机 Chromium / Playwright 的五条完整界面流程
npm run test:offline     # 构建单文件后的断网交互验证
npm run build:offline    # 生成可直接双击打开的单文件离线 HTML
```

界面测试会按需启动本地服务器；优先使用 `/usr/bin/chromium`。其他环境先执行 `npx playwright install chromium`，也可以通过 `CHROMIUM_PATH` 指定可执行文件。CI 会自动安装浏览器并运行同一组检查。

`dist/` 可部署到任意静态托管。无需后端或环境变量。离线 HTML 将脚本、样式和美术全部内嵌；不同文件名、浏览器或网站的本地存档通常彼此隔离，切换版本前请导出存档。

## 操作

点击主图地点或右侧旅事交互。WASD / 方向键移动提灯人，E 与最近地点交互；M 打开舆图，J 打开旅记，I 打开行囊。手机使用地点按钮与回廊方向键。

回廊内逐格移动。三盏符灯组成闭环：踩青改变青与朱，踩朱改变朱与金，踩金改变金与青。使灯的状态与出口灯谱一致，再持本层铜钥走到出口。旧札、补给和守卫均只记录一次，不会刷新。关掉地图面板可以回营地准备，再从原处继续。

战斗中，普攻恢复灵力；引灯术消耗 3 灵力并削韧；凝神减少 75% 伤害并积累共鸣；3 共鸣可施放破雾。看见蓄力时准备应对下一回合重击。敌人韧性归零会跳过当回合行动。

## 剧情与结局

完整大纲、每章冲突、人物动机与时长目标在 [docs/STORY.md](docs/STORY.md)。

“归灯”和“远行”完成主线后可选。“破晓”还需要至少四份支线旧物与四次尊重他人意愿的选择。可以回访旧章节补做支线，但不能通过重读已完成的抉择更换答案。想比较不同选择时使用手动存档。

## 代码

- `src/rpg/content.mjs`：八章场景、对白、奖励、先决条件、首领与结局。
- `src/rpg/expeditions.mjs`：24 张回廊与移动、视野、符灯机关。
- `src/rpg/engine.mjs`：纯状态逻辑，战斗、资源、成长及存档验证。
- `src/rpg/Expedition.jsx`：回廊界面。
- `src/App.jsx`：主图、对白、战斗、旅记、行囊、设置与存档。
- `public/art/`：本地美术；来源与使用方式见 [docs/ART.md](docs/ART.md)。
- `tests/`：从新游戏贯通八章、所有地图可解性、两条选择路线及三结局的验证，以及桌面/手机真实浏览器流程。

存档只采纳允许的字段，旧物与线索文字从本地内容重新构建，不渲染存档提供的任意 HTML。损坏文件不会覆盖有效进度。源码与离线构建都不依赖外部图片或在线字体。
