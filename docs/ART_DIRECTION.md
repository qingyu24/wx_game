# 美术与操作重做目标

2026-11-06：用户明确认为新增像素场景的美术退步，操作仍过于简陋。本轮不再沿用程序方块人物、树木与怪物作为正式美术。

## 保留的方向

原有四位人物肖像、八种首领和章节插画作为风格基准：东方幻想、细腻手绘材质、青黛苔绿与暖金灯光、可信的人物比例。保留原有形象识别、剧情和玩家存档，不重新发明一套卡通人物。

## 制作顺序

1. 先制作可用的角色与怪物透明素材、统一比例与镜头，以及有明确道路和战斗空间的村落地图。
2. 主角补方向和移动动画。人物与怪物都以脚底为定位点，不能仅把肖像贴在地面上。
3. 先完成序章一张地图：移动、点击交互、接敌、普攻连招、技能、受击、闪避、掉落、回营和存档形成闭环。
4. 桌面支持鼠标选敌与移动；手机使用自由方向摇杆和明确的技能反馈，交互对象靠近后直接提示。
5. 验证角色比例、场景可读性、攻击范围、动作反馈和手机手感，再扩展其他章节。

## 本轮验收

- 正式场景使用与原插画一致的绘制素材，不以方块/几何图形充当最终人物与怪物。
- 行走、攻击、受击和闪避有可辨识的动作状态；施法、命中和被打的反馈不同。
- 敌人必须有可读的出招过程与躲避机会，玩家移动和选敌能影响战斗。
- 场景有实际边界、桥梁和通行路线，人物比例与场景相符。
- 默认界面以场景和交互为主，长对白可自选阅读，避免依靠文字面板推进全部玩法。
- 桌面与手机真实浏览器验证后，再更新 Sites 与 GitHub Pages。

## 发布状态

本轮在完整浏览器验收后更新 Sites，并将美术与操作代码通过 PR 同步 GitHub；GitHub Pages 使用先检查、再部署的流水线，是否成功上线以部署任务返回为准。

## 已完成的第一轮素材与实现

六套手绘素材已生成并接入场景，`public/art-review.html` 提供完整预览。主角使用四方向行走和动作图集；加入自由方向摇杆、点选敌人接战、点选宝箱/人物走近交互、命中停顿、击退与远程鳞粉攻击。地图加入弯曲河道、两座桥、房屋与大树边界。旧像素地图的位置检查点迁移回营地，保留剧情、道具、金币与探索奖励。

页面子路径和离线打包一起验证；新版本在通过真实浏览器操作回归后才发布。
