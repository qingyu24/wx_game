# 雾灯归途 · 剧情与流程设计

## 创作基调

东方山城幻想，温柔但有代价的冒险。没有救世血统：主角沈砚是修灯学徒，姐姐沈栖在三年前的灯祭失踪。青黛、苔绿、旧金、朱砂点色；手绘纸纹、克制的光效，禁止签到、排行榜、抽奖和手机外壳。游戏为中文单机网页 RPG，鼠标/触屏与键盘均可操作。

## 核心悬念与答案

雾不是怪物释放的诅咒，而是城中人自愿交出的痛苦记忆。灯塔将记忆作为燃料，防止旧日山洪的亡魂吞没山城。姐姐成为守灯人后发现：被遗忘的并不只有痛苦，也包括承诺、名字与反抗的能力。她拆下六枚灯芯，等待有人替整座城作出清醒的选择。

沈砚的目标从“把姐姐带回来”变成“让每个人决定自己的记忆”。同行者闻笙是失去儿子姓名的摆渡人，阿绫是被当作祭品却仍会开玩笑的纸偶；旧守灯人陆衡并非恶人，他记得每一个被洪水夺走的人。

## 每章的可玩结构

安全落脚点 → 三个调查节点（对白/线索/小谜题）→ 可选人物支线 → 资源取舍 → 有预告的精英战 → 首领 → 营地对话 → 下一章。场景分别手写，不把同一段文本改名充数。

战斗采用公开敌方意图的回合制：普攻恢复灵力；灯术消耗灵力并削韧；防御降低伤害；照明蓄出共鸣后施放破雾；药品有限但可在营地补给；失败回到本章营地，不删除剧情或背包。首领轮换蓄力、守势和虚弱，不做纯数值木桩。

探索获得灯油、药材、铜钱、旧物；旧物有固定出处、文本和一次性标记。三类装备可升级：灯（灯术）、刃（普攻）、衣（护甲）。伙伴随剧情加入，不可抽取。支线以独立标记追踪并提供证词/资源，不要求重复击杀。

## 三种结局

1. **归灯**：接受陆衡的方案，沈砚接替守灯，姐姐和居民得以活下去；失去记忆的人仍不知道自己的代价。
2. **破晓**：保留至少四份证词并多次尊重当事人的选择，将六芯分发给居民共同承担。天亮后每人记得悲伤，也记得彼此。
3. **远行**：关闭灯塔，带姐姐与愿意离开的人穿过雾海；山城留给拒绝离开的人，结尾展示曾被帮助者的去向。

## 实现与验收

剧情与资源定义保持数据驱动；状态机隔离战斗、对话、地图和存档。新游戏、自动存档、手动存档、导入导出、失败重试、章节解锁、道具消耗、支线一次性奖励都需要真实工作。存档版本检查，错误导入不能覆盖有效进度。任何未达到上表时长的版本必须明确标注，不能把章节数量当作十小时完成度。

## 美术生成清单

先生成同一世界观的八幅章节横幅（无文字、无界面），再生成沈砚/闻笙/阿绫/沈栖肖像与敌人图。素材保存在 public/art，必须可离线加载。游戏场景以这些素材为背景，并叠加真正可交互的调查热点、角色与路径。
