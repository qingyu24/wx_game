# 美术素材

本次重构通过 AI 图像生成制作素材，然后接入本地游戏。风格统一为东方山城幻想：青黛、苔绿、旧金、暖灯，带纸纹的水墨与不透明水彩质感。素材是叙事空间，不再使用夸张霓虹、抽奖盘或手机壳。

章节背景分别生成；肖像和敌人使用图集定位，角色使用透明图片。回廊内地面、墙体、视野、符灯和路径由程序实际绘制，并非一张不可交互的场景概念图。音乐使用 Web Audio 合成，不依赖远程音频。

素材仅做面向网页的格式与体积优化，原始生成文件留在生成工作区。交付源码保留运行所需的本地 WebP，无需第三方图片链接或临时生成 URL。

## 实景探索像素美术

新增的 `src/rpg/ActionWorld.jsx` 使用 Canvas 本地绘制草地、针叶与阔叶树、木屋、围栏、灯柱、双桥河道、遗迹、人物与雾灵。材质细节使用确定性噪声，场景不依赖外部贴图或图像接口；镜头跟随角色，近战弧光、范围灯术、攻击预警与闪避闪烁由实时状态驱动。青绿、苔色和暖金延续原有配色。原章节插画继续用于标题、剧情地图和结局。

目前各章实景探索共用地形、按章节轻调色；人物地点与有限奖励按章独立。不能将它描述为八套独立制作的像素地图。
