# 美术素材

本次重构通过 AI 图像生成制作素材，然后接入本地游戏。风格统一为东方山城幻想：青黛、苔绿、旧金、暖灯，带纸纹的水墨与不透明水彩质感。素材是叙事空间，不再使用夸张霓虹、抽奖盘或手机壳。

章节背景分别生成；肖像和敌人使用图集定位，角色使用透明图片。回廊内地面、墙体、视野、符灯和路径由程序实际绘制，并非一张不可交互的场景概念图。音乐使用 Web Audio 合成，不依赖远程音频。

素材仅做面向网页的格式与体积优化，原始生成文件留在生成工作区。交付源码保留运行所需的本地 WebP，无需第三方图片链接或临时生成 URL。

## 手绘实景重做（2026-11-06）

原程序像素角色与几何场景退出正式画面。新增素材以原有肖像、首领及章节场景为参照，通过图像生成工具制作：

| 文件 | 内容与用途 |
| --- | --- |
| `rework/characters.webp` | 四位主角的透明全身图集，用于场景人物 |
| `rework/monsters.webp` | 食忆蛾、雾狼、石魇与蛾王透明图集 |
| `rework/hero-walk.webp` | 四方向、每方向四帧行走 |
| `rework/hero-actions.webp` | 四方向攻击、施法、受击与闪避姿态 |
| `rework/village.webp` | 带双桥、营地、村落和遗迹的可走地图 |
| `rework/props.webp` | 宝箱、开启宝箱、营火炉和符灯机关 |

原始 PNG 留在生成工作区，项目保留运行所需的 WebP。只做格式与体积优化；人物、怪物和地图内容通过图像生成制作。运行时按透明范围定位图集帧，人物脚底作为世界坐标，按脚底深度排序；界面不以方块角色作为图片加载失败后的替代。

目前主要打磨第一张村落地图；后续章节仍暂共用地形。原有八章插画、人物肖像和首领回合战图集均保留，不把这次制作描述为八张独立新地图。
