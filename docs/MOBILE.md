# 手机优先版

本轮目标：保留手绘美术，将第一张地图改为横屏手机 H5 动作 RPG。浏览器可以直接玩；支持的平台可以添加到主屏幕，后续再接微信小游戏的画布、设备和存储接口。

首次手游改造时暂缓了 GitHub 发布。2026-11-06 按用户后续指示，已将手游源码同步到 qingyu24/wx_game 的 main，并通过 GitHub Actions 发布 Pages；构建产物同时加入 qingyu24/web 的 public/mist-lantern/。Cloudflare 手游入口为 https://rpg.chenbao.fun/，沿用同一份 Pages 内容。

## 操作与界面

- 进入游戏后是完整战斗视口，移除常驻网页页头、页脚和重复状态栏。
- 左摇杆有死区与轻推慢走；右手长按普攻，第三根手指仍可点击灯术或闪避。
- 闪避优先跟随摇杆方向，方向在闪避开始时固定，避免被普攻自动朝向带偏。闪避冷却 1.1 秒，无敌窗短于冷却，不能连续无敌。
- 灯术有冷却与消耗；药草有独立冷却，触屏和键盘都不能连点重复消耗。
- 右上提供地图、行囊、旅记、全屏、操作与暂停。任务面板默认折叠。
- 切后台自动保存与暂停；页面离开时同步保存位置、生命和灵力。恢复前需要玩家点继续。
- 竖屏可继续玩，并提供可关闭的横屏建议；不强制旋转网页坐标。
- 安全区处理刘海与底部手势区域。全屏与方向锁定是否支持由浏览器决定。

## 安装与离线

- `public/manifest.webmanifest` 提供独立窗口、横屏偏好和主屏幕图标。
- `scripts/mobile-package.mjs` 在构建后生成有版本号的 Service Worker，缓存脚本、样式和游戏美术；缓存与请求限制在当前游戏路径，避免影响同域的其他项目。
- 离线资源准备好后暂停菜单会显示就绪。资源未准备好或浏览器不支持时不宣称已经可以离线。
- 有新版本时在暂停菜单提供重新载入入口，不在战斗中强制刷新。
- 支持安装提示的浏览器可从暂停菜单安装；iPhone 可通过 Safari 分享菜单添加到主屏幕。
- 单文件离线 HTML 继续保留，但不把本地文件当作可安装 PWA。

## 验证

`npm test` 运行规则、存档及手机输入规则测试。

`npm run test:browser` 包含原剧情、实景操作和手机多点触控测试。手机测试覆盖 844×390、667×375、390×844，使用浏览器原生触控事件检查移动/普攻/技能组合、定向闪避、药草冷却、切后台暂停、暂停菜单与原有遭遇控制。

`npm run build:offline` 后执行 `npm run test:mobile:offline`，验证主屏幕安装清单、游戏路径内的缓存，以及断网冷启动和继续游戏。

这些是浏览器与手机尺寸的模拟验证，不能替代不同手机的真机帧率、触感和系统全屏行为检查。
